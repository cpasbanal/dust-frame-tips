Frames That Stay Put
Dust tips · Frames & dashboards

Build the frame once.
Let an agent refresh the data.

If your scheduled agent builds the whole dashboard on every run, it redesigns it every time. Split the work: design the frame in a conversation, then give a small agent one job, which is updating the numbers inside it.

Frame = structure · built once, by you Data = values · refreshed by the agent
The problem

One agent doing everything reinvents the dashboard

Avoid All-in-one agent

Monday · Tuesday · Wednesday
  • Layout, charts and labels change from run to run
  • Every run burns tokens redesigning instead of updating
  • Nobody can bookmark or compare a stable view

Do Frame + refresh agent

Monday · Tuesday · Wednesday
  • Same layout every time; only the numbers move
  • Short, cheap runs with a narrow job
  • One URL the whole team can trust
The method

Three steps, in this order

Example used below: a weekly team KPI dashboard.

1

Get the data right in a conversation

Where: a normal Dust conversation
  • Start small. Ask for 2–3 sources or KPIs and have the agent return them as a table in the conversation.
  • Check the numbers are correct before you think about design.
  • Note exactly where each value comes from. The refresh agent will need it.
2

Design the frame in a separate conversation

Where: a new conversation dedicated to the frame
  • Paste the table and ask for a Dust frame (dashboard) that shows it the way you want.
  • Iterate on layout, charts, labels and colors until you are happy. This is the only place the design changes.
  • Copy the frame URL. That URL is the contract with your agent.
3

Create a refresh agent and give it a schedule trigger

Where: Agent Builder → instructions, then Triggers → Add triggers → Schedule
  • Paste the frame URL into the agent's instructions and say explicitly that it must update data only, never the structure. Template below.
  • Give it only the tools and data sources it needs to fetch the values.
  • Add a Schedule trigger in plain language (e.g. "every Monday at 8 AM, Paris time"), check the confirmed schedule, then save the agent.
Copy this

Refresh agent instructions

Replace the amber parts. Keep the "do not change" lines: they are what stops the agent from redesigning your frame.

Agent instructions
You keep an existing Dust frame up to date. You never redesign it.

Frame to update: [paste the frame URL]

On every run:
1. Fetch the latest values from [your sources: table, data source, websites…].
2. Open the frame above and replace only the data: numbers, table rows, dates and the "last updated" stamp.
3. Do not change the structure: keep the layout, sections, charts, labels, colors and code exactly as they are.
4. Do not create a new frame. Always edit the one at the URL above.
5. If the new data no longer fits the frame (new column, missing source, broken value), stop and explain the problem in the conversation instead of changing the frame.
6. End with a 3-line summary: what changed since the last run, and anything missing.
Why a trigger

Use a trigger, not a wake-up

A wake-up is something an agent schedules for itself when you ask it in a conversation to "do this every week". A trigger is a schedule you set on the agent. For a dashboard refresh, you want the trigger.

Schedule triggerWake-up
Who sets itYou, in Agent Builder → TriggersThe agent, from inside a conversation
Where you see itOn the agent, with the confirmed schedule; enable, disable or delete it anytimeHidden in the conversation that created it
Instructions usedThe agent's own instructions, which you edited to protect the frameWhatever context that conversation had, including the redesign history
LifetimeRuns until you stop itSchedule-based wake-ups stop after 32 runs
Good habits

Keep it light and shared

Don't send it by email

Emailing the result costs tokens and adds little. Come back to Dust and open the frame: it is always the latest version.

Pin the frame to a Pod

Work on the dashboard together in a Pod and pin the frame there, so the team finds the one current view without searching.

Change the design on purpose

Need a new chart? Go back to the frame conversation (step 2), change it there, and keep the same URL.

Read the run summary

Trigger runs show up as conversations. Skim the 3-line summary to spot a missing source before it shows on the dashboard.
